# Claude Code 終端機優化設定（Windows 版）

## 已套用的設定

設定檔位置：`C:\Users\he014\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`

### 功能說明

| 指令 | 功能 |
|------|------|
| `cc` | 切換到工作目錄 + 啟動 Claude Code |
| `ccd` | 只切換到工作目錄（不啟動 Claude） |

### 環境變數

- `CLAUDE_CODE_NO_FLICKER=1` — 防止畫面閃爍，啟用滾輪回看與滑鼠選取

---

## 如何生效

每次重新開啟 PowerShell 後會自動載入設定。

若要**立即生效**，在 PowerShell 執行：
```powershell
. $PROFILE
```

---

## 常見問題

### 出現「執行原則」錯誤？
以**系統管理員身份**開啟 PowerShell，執行：
```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 想修改工作目錄？
編輯設定檔 `C:\Users\he014\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`，修改路徑即可。
