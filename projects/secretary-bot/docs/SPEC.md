|------|------|
| `/todo add <內容>` | 新增待辦 |

| 指令 | 說明 |
|------|------|
| `/stock buy <代號或名稱> <股數> [價格]` | 記錄買入（例：`台積電 1張 900`；股數可填「張」=1000股；價格留空自動用目前市價） |
| `/stock sell <代號或名稱> <股數> [價格]` | 記錄賣出（計算實現損益；用法同上） |
| `/stock batch <文字>` | 一次記錄多筆買賣（例：`昇達科賣出5股2200 定穎投控賣出10股187`；用空白分隔每筆，價格可省略用目前市價） |
| `/stock pnl` | 查看未實現損益 |
| `/stock list` | 列出目前持股 |
| `/stock calc <代號或名稱> <股數> [假設價]` | 試算損益（不動資料；假設價留空用目前市價） |
| `/stock delete <id>` | 刪除交易紀錄 |

### 設定模組

| 指令 | 說明 |
|------|------|
| `/config push_time <HH:MM>` | 設定每日推送時間（例：`08:30`） |
| `/config weekly_time <HH:MM>` | 設定週報推送時間（預設：`18:00`） |
| `/config weekly_day <星期>` | 設定週報推送星期（預設：`週日`；可填 `週日`、`禮拜日`、`日`、`0`、`7`） |
| `/config channel <頻道ID>` | 設定推送頻道 |

### 學習模組

| 指令 | 說明 |
|------|------|
| `/learn <術語>` | 查詢台股術語說明 |
| `/learn reset` | 重置「已學過」紀錄，下次推送重新顯示新手說明 |

## 四、股票 P&L 計算邏輯

> 股數輸入若帶小數（例如「5.7股」「1.9張」），無條件捨去取整數，不四捨五入。

### 加權平均成本

```
每次買入記錄：股數 × 成本價
加權平均成本 = 所有買入總金額 / 總持股數
未實現損益 = (現價 - 加權平均成本) × 目前持股數
報酬率 % = (現價 - 加權平均成本) / 加權平均成本 × 100
```

### 整體損益統整

```
總投入成本 = Σ (各持股加權均價 × 持股數)
總市值     = Σ (各持股現價 × 持股數)
總損益     = 總市值 - 總投入成本
整體報酬率 = 總損益 / 總投入成本 × 100
```

- 🟡 黃色（Discord ANSI 33）= 持平 / 中性

## 九、資料庫結構（SQLite）

```sql
-- 待辦
CREATE TABLE todos (
    id       INTEGER PRIMARY KEY,
    content  TEXT NOT NULL,
    done     INTEGER DEFAULT 0,
    created  TEXT DEFAULT (datetime('now'))
);

-- 股票交易
CREATE TABLE transactions (
    id       INTEGER PRIMARY KEY,
    ticker   TEXT NOT NULL,     -- e.g. '2330'
    name     TEXT,              -- e.g. '台積電'
    shares   INTEGER NOT NULL,
    cost     REAL NOT NULL,     -- 每股成本
    type     TEXT DEFAULT 'buy', -- 'buy' | 'sell'
    created  TEXT DEFAULT (datetime('now'))
);

-- 設定
CREATE TABLE config (
    key      TEXT PRIMARY KEY,
    value    TEXT
);
-- key: 'push_time', 'weekly_time', 'weekly_day', 'channel_id'

-- 已學術語（新手模式）
CREATE TABLE learned_terms (
    term     TEXT PRIMARY KEY,
    learned  TEXT DEFAULT (datetime('now'))
);

-- 秘書記憶：每日/週報重點，後續報告會納入參考
CREATE TABLE memories (
    id          INTEGER PRIMARY KEY,
    kind        TEXT NOT NULL,   -- daily_report | weekly_report
    content     TEXT NOT NULL,
    source_date TEXT NOT NULL,
    created     TEXT DEFAULT (datetime('now')),
    UNIQUE(kind, source_date)
);
```
