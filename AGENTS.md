# FlyCat Workspace Rules

## Twitch Bot And Public Website

- The private Twitch BOT source is maintained in `D:\tset\bot_private`.
- The public command website is maintained in `D:\tset\FlyCatClaude Code\index.html`.
- Whenever a user-facing BOT command, permission, behavior, message, or version changes, update the matching website explanation in the same task.
- Verify website changes at desktop and mobile widths before considering the feature complete.
- Never publish `.env` values, channel configuration, tokens, API keys, databases, or other private runtime data to the public website repository.
